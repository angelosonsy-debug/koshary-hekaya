# koshary-hekaya
Fully responsive restaurant website simulating a real online ordering system with menu filtering, cart management, and checkout flow.


## 🌐 Live Demo

[Visit the live site](https://angelosonsy-debug.github.io/koshary-hekaya/)

## ✨ Features

- Fully responsive layout for mobile, tablet, and desktop
- Dynamic menu filtering by category and branch
- Cart system with quantity control
- Persistent cart using `localStorage`
- Branch switching with confirmation modal
- Delivery zones with branch-based pricing
- Checkout flow with order summary
- Payment confirmation page
- Success page with countdown and live order status
- Smooth reveal animations and premium hover effects
- SEO-friendly structure with Open Graph metadata
- Google Maps embed with fallback handling

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage API
- Google Maps Embed
- Responsive design principles
